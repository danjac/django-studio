**/djs-help [command]**

Lists all available djs-* commands, or shows detailed help for a specific command.

Without arguments: prints all commands with their one-line description.
With a command name: prints the full help for that command.
The `djs-` prefix is optional.

Examples:
  /djs-help              # list all commands
  /djs-help a11y         # show help for /djs-a11y
  /djs-help djs-a11y     # same thing
